# Investment Tracker App — Project Roadmap

## Project Goal

Build a simple, clean, sellable Investment Tracker application using:

- PHP
- Laravel
- MySQL
- HTML
- CSS
- JavaScript
- Tailwind CSS

The application should be simple, reliable, easy to understand, and suitable for selling as a small PHP product.

# Development Rules

1. Work on only one task at a time.
2. Do not implement future-version features early.
3. After completing a task:
   - Test it.
   - Mark the task `[x]` in WORK_ITEMS.md.
   - Commit the change to Git.
4. Never depend on ChatGPT conversation history.
5. GitHub files are the source of truth.
6. Before starting work, read:
   - PROJECT_ROADMAP.md
   - WORK_ITEMS.md
7. Continue from the first unchecked task.
8. Do not make unnecessary architectural changes.
9. Keep the application simple.
10. Avoid feature bloat.
